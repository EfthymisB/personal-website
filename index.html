Software engineer building production pipelines for film and television.

I'm a Senior Pipeline Technical Director at One Of Us in London. I design and build the services, tools and automation that carry work through a visual effects studio, from an artist's scene file to a delivered shot.

Most of the job is software engineering: backend services and APIs, desktop applications, build and release infrastructure, and a lot of data moving between systems that can't afford to break mid-production. Increasingly it's also about putting agentic AI tooling to work in how that software gets written and run.

What I work on

Pipeline services
Export and publish systems at the core of the studio pipeline: the code every department's work passes through on its way to the client.
Tooling
Python and Qt applications for artists, plus integrations with Houdini, Maya, Nuke, RV and Flow Production Tracking (ShotGrid).
Build & release
CI/CD, source builds and software environments, along with Bash utilities and Linux services for studio-wide automation.
Imaging
Colour-managed image workflows built on OpenImageIO and OpenColorIO.
AI tooling
Agentic coding as a daily workflow; tool-calling agents, local models through Ollama, and RAG and MCP integrations for pipeline tools.
